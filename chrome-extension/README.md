# Pomodorus — Chrome Extension

یه پومودوروی مینیمال، همون فلسفه‌ی [Pomodorus](../README.md) اما به شکل اکستنشن کروم: بدون اکانت، بدون بک‌اند، همه‌چی رو همون دستگاه.

این نسخه یه پورت مستقل و لوکال-فرست از تایمر وب‌اپه (نه یه wrapper دور اون). هیچ درخواستی به هیچ سروری نمی‌زنه؛ همه‌چی (تسک‌ها، تنظیمات، تاریخچه‌ی فوکوس) تو `chrome.storage.local` همون مرورگر ذخیره میشه.

## چی داره

- تایمر پومودورو با استپر ۱۵ تا ۶۰ دقیقه (پیش‌فرض ۲۵، پله‌های ۵ دقیقه‌ای)
- چیل کوتاه / چیل حسابی با تناوب قابل تنظیم (پیش‌فرض ۲۵ / ۵ / ۲۰، هر ۴ تا)
- تسک‌های لوکال (پابلیک/خصوصی فقط به‌عنوان لیبل بصری — همه‌چی همینجا می‌مونه)
- زنگ با WebAudio + system notification وقتی پاپ‌آپ بازه یا حتی بسته باشه
- بج آیکون با شمارش معکوس دقیقه‌ی باقی‌مونده
- شمارنده‌ی سیکل و خلاصه‌ی «امروز چقدر فوکوس کردی»
- کاملاً افلاین، کاملاً محلی — هیچ اکانتی، هیچ فیدی، هیچ سروری در کار نیست

## چیزی که عمداً نیست

نسخه‌ی وب یه بک‌اند Convex برای اکانت، فید عمومی و پروفایل داره. اینا آگاهانه از نسخه‌ی اکستنشن حذف شدن چون:

- اکستنشن‌های کروم پاپ‌آپشون با از دست دادن فوکوس آنلود میشه — نگه‌داشتن سشن لاگین معنی نداره
- «کیا الان دارن کار می‌کنن» تو یه اکستنشن شخصی، تک‌کاربره فایده‌ای نداره
- بدون سرور یعنی بدون هیچ داده‌ای که جایی جز مرورگر خودت بره

## نصب برای توسعه (Load unpacked)

1. برو `chrome://extensions`
2. «حالت توسعه‌دهنده» / Developer mode رو روشن کن
3. «بارگذاری بسته‌باز‌نشده» / Load unpacked رو بزن
4. پوشه‌ی `chrome-extension/` همین ریپو رو انتخاب کن

## معماری کوتاه

- `lib/engine.js` — منطق خالص تایمر (state machine)، بدون هیچ وابستگی به chrome.* — قابل تست جدا
- `lib/storage.js` — wrapper رو `chrome.storage.local`
- `lib/actions.js` — اکشن‌های کاربر (شروع، کنسل، اسکیپ، تایید) که state رو با engine جابه‌جا می‌کنن و ذخیره می‌کنن
- `lib/background.js` — service worker: زنگ‌های سررسیده رو حتی وقتی پاپ‌آپ بسته‌ست تشخیص می‌ده (`chrome.alarms`)، بج آیکون رو آپدیت می‌کنه، notification سیستمی می‌فرسته
- `popup/` — رابط کاربری پاپ‌آپ (وانیلا JS، بدون فریم‌ورک)
- `options/` — صفحه‌ی تنظیم تایمرها

مدل «local-first» دقیقاً از `SPEC.md` نسخه‌ی وب اقتباس شده: `startedAt` + `duration` منبع حقیقتن، هیچی خودکار جلو نمی‌ره، فقط یه تاییدِ صریح زنگ رو قطع می‌کنه.
