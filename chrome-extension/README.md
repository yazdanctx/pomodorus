# Pomodorus — Chrome Extension

یه پومودوروی مینیمال، همون فلسفه‌ی [Pomodorus](../README.md) اما به شکل اکستنشن کروم — و این نسخه واقعاً به همون بک‌اند Convex پروداکشنِ وب‌اپ وصله: همون اکانت، همون فید، همون پروفایل.

تایمر خودش کاملاً local-first می‌مونه (منبع حقیقت `chrome.storage.local`ه، همه‌چی حتی بدون لاگین و بدون نت کار می‌کنه)، ولی اگه لاگین کنی، دقیقاً مثل وب‌اپ: تسک‌هات سینک میشن، سشن‌های تموم‌شده میرن تو تاریخچه‌ی سرور، وقتی داری کار می‌کنی تو فید عمومی دیده میشی، و پروفایلت رو با نمودار فوکوس هفته‌ی اخیر می‌بینی.

## چی داره

- تایمر پومودورو با استپر ۱۵ تا ۶۰ دقیقه (پیش‌فرض ۲۵، پله‌های ۵ دقیقه‌ای)، چیل کوتاه/حسابی با تناوب قابل تنظیم
- **لاگین واقعی** — همون فلوی یوزرنیم+پسورد وب‌اپ (یه فرم، یه دکمه؛ ناشناس = ثبت‌نام، شناخته‌شده = ورود)، روی همون دیپلوی Convex پروداکشن (`convex/auth.ts`)
- **فید زنده** — تب «کیا آنلاینن؟» هر ۴ ثانیه از سرور واقعی می‌پرسه کی الان داره کار می‌کنه یا چیل می‌کنه؛ کار می‌کنه چه لاگین باشی چه نه
- **پروفایل** — یوزرنیم، جمع فوکوس هفته‌ی اخیر، و یه نمودار میله‌ای ساده (svg دستی، بدون کتابخونه)
- **سینک تسک‌ها و تاریخچه** — ساخت/ادیت/حذف تسک وقتی لاگینی صف میشه و به `sync:push` واقعی پوش میشه؛ last-write-wins دقیقاً مثل وب‌اپ
- **حضور (presence)** — شروع سشن، وقتی لاگینی، تو رو تو فید عمومی نشون می‌ده؛ کنسل/اسکیپ/تمومِ سشن پاکش می‌کنه
- زنگ با WebAudio + system notification، بج آیکون با شمارش معکوس، شمارنده‌ی سیکل
- **کاملاً کار می‌کنه بدون لاگین هم** — تایمر و تسک‌های لوکال همیشه در دسترسن؛ لاگین فقط سینک/فید/پروفایل رو باز می‌کنه

## چیزی که فرق داره با وب‌اپ (آگاهانه)

- اکستنشن‌ها هیچ‌وقت auth رو اجباری نمی‌کنن روی تایمر — پاپ‌آپ با از دست دادن فوکوس آنلود میشه، اجبار به لاگین فقط اصطکاکه بدون فایده
- به‌جای WebSocket زنده (که با آنلود شدن پاپ‌آپ هرجا قطع میشه)، فید و پروفایل با HTTP poll کار می‌کنن — ساده‌تر و قابل‌اعتمادتر برای یه پاپ‌آپ کوتاه‌عمر
- بدون صفحه‌ی پروفایل عمومی جدا (`/u/[username]`) — تب «اکانت» فقط پروفایل خودتو نشون می‌ده

## نصب برای توسعه (Load unpacked)

1. برو `chrome://extensions`
2. «حالت توسعه‌دهنده» / Developer mode رو روشن کن
3. «بارگذاری بسته‌باز‌نشده» / Load unpacked رو بزن
4. پوشه‌ی `chrome-extension/` همین ریپو رو انتخاب کن

## معماری کوتاه

- `lib/engine.js` — منطق خالص تایمر (state machine)، بدون هیچ وابستگی به chrome.* یا شبکه — قابل تست جدا
- `lib/storage.js` — wrapper رو `chrome.storage.local` (state، تنظیمات، تسک‌ها، تاریخچه، auth، صف‌های سینک)
- `lib/actions.js` — اکشن‌های کاربر (شروع، کنسل، اسکیپ، تایید) — state رو با engine جابه‌جا می‌کنه، تاریخچه رو ثبت می‌کنه، و اگه لاگینی presence/سینک رو best-effort صدا می‌زنه
- `lib/backend.js` — کلاینت Convex (روی `lib/vendor/convex.bundle.js`، باندل‌شده با esbuild)؛ auth، query/mutation/action های واقعی
- `lib/sync.js` — صف local-first برای category ops و سشن‌ها، push/pull با سرور، دقیقاً همون قرارداد `convex/sync.ts` وب‌اپ
- `lib/categories.js` — CRUD تسک‌ها، لوکال‌فرست + صف‌بندی برای سینک
- `lib/background.js` — service worker: زنگ‌های سررسیده رو حتی وقتی پاپ‌آپ بسته‌ست تشخیص می‌ده، بج آیکون رو آپدیت می‌کنه، notification می‌فرسته، و هر ۲ دقیقه صف سینک رو retry می‌کنه
- `popup/` — رابط کاربری (وانیلا JS، بدون فریم‌ورک) با ناوبری تایمر/فید/اکانت
- `options/` — صفحه‌ی تنظیم تایمرها

مدل «local-first» دقیقاً از `SPEC.md` نسخه‌ی وب اقتباس شده: `startedAt` + `duration` منبع حقیقتن، هیچی خودکار جلو نمی‌ره، فقط یه تاییدِ صریح زنگ رو قطع می‌کنه؛ Convex یه لاگه نه منبع حقیقت.

## ساخت مجدد باندل Convex

`lib/vendor/convex.bundle.js` از `convex/browser` با esbuild ساخته شده (چون MV3 اجازه‌ی لود اسکریپت از CDN نمی‌ده — باید لوکال باندل بشه). برای ساخت دوباره:

```bash
npm install
npm run build:extension
```
